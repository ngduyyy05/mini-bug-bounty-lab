Verified locally on **1 November 2026 (Asia/Bangkok)** using Docker Desktop's Linux engine. Both independent Apache applications and their separate MySQL databases were healthy at completion.

## Executed checks

```sh
docker compose up -d --build --wait
docker compose run --build --rm tests
docker compose run --rm tests php scripts/poc.php 06
docker compose exec -T app-fixed composer validate --no-check-publish
docker compose exec -T app-vulnerable composer validate --no-check-publish
docker compose run --rm --no-deps tests composer validate --no-check-publish
docker compose run --rm --no-deps tests composer audit
```

Full suite: **27 tests, 273 assertions, zero failures, errors or skips**. The standalone JWT PoC entry point also passed both applications: **2 tests, 7 assertions**. All three Composer manifests validated; the root dependency audit reported no security vulnerability advisories. Application PHP sources and templates passed syntax checks during Docker builds. Rendered inline JavaScript from `/` and `/login` on both ports parsed successfully using Node's JavaScript parser.
