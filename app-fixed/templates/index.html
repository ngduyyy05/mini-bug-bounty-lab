04 / Reviewer notes

Designed for a technical conversation.

What does this project demonstrate?

API authorization testing, injection analysis, JWT trust, browser rendering, business logic abuse, remediation review and automated regression checks. This is a deliberately seeded training lab, not a claim of findings in a production system.

How should I review it in five minutes?

Run the IDOR check here, repeat it on the other local instance, inspect order_detail in both main.py files, then run the regression suite. Review docs/demo-playbook.md for a guided interview walkthrough.

What are the limits of the fixed version?

It is an educational comparison, not a production security baseline. The browser app uses localStorage tokens, logout does not revoke JWTs, upload checks use extension and declared MIME, and login throttling is held in process memory. See docs/security-boundaries.md.
